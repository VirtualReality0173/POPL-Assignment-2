A binary tree is represented as either:
- The empty list `()`.

- Use `#lang racket/base`.

# S1.c – Binary Tree Height and Leaf Count

## Task

Implement the function `print-height-and-leaves` in Scheme/Racket.

A binary tree is represented as either:
- The empty list `()`.
- A three-element list `(value left right)`.

The function must print a two-element list containing:

1. The height of the binary tree.
2. The number of leaves in the binary tree.

## Definitions

- Height of an empty tree is 0.
- Height of a nonempty node is 1 plus the maximum height of its left and right subtrees.
- A leaf is a node whose left and right subtrees are both empty.
- The empty tree has zero leaves.

## Constraints

- Use `#lang racket/base`.
- Follow the assignment's restricted Scheme/Racket built-in requirements.
- Do not use mutation or prohibited list operations.
- Reuse existing `tree-height` and `leaf-count` helper functions if available.
- Use `display` to print the result and `newline` to terminate the line.
- Do not print labels or additional explanatory text.
- Keep the implementation in `code/43_q3.rkt`.
- Do not include top-level test calls in the implementation file.

## Expected behaviour

For the tree:

```racket
'(4 (2 (1 () ()) (3 () ()))
    (6 (5 () ()) (7 () ())))
```

Expected output:

```text
(3 4)
```

For an empty tree, expected output:

```text
(0 0)
```

Provide the implementation of `print-height-and-leaves` and briefly explain its behaviour.
